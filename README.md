# APEX Essential 모의시험

생성형 AI 역량 인증시험(APEX Essential) 대비 모의시험 사이트입니다. 의존성 없는 단일 HTML 파일이라 정적 호스팅 어디에나 그대로 올릴 수 있습니다.

## 구성

| 파트 | 유형 | 문항 | 배점 | 채점 |
|---|---|---|---|---|
| Part 1 | 객관식 4지선다 | 30 · 25분 | 300점 | 자동 |
| Part 2 | 실습형 (순서 설계·복수선택·프롬프트 작성) | 15 · 15분 (은행 30) | 300점 | 자동 + 루브릭 자가채점 |
| Part 3 | 개발·IT 시나리오 서술형 | 5 · 100분 (은행 20) | 400점 | 루브릭 자가채점 |

- 제한 시간 140분, 총 1,000점
- **합격 기준: 총점 600점 이상 + 6대 역량 모두 50점(100점 환산) 이상.** 한 역량이라도 50점 미만이면 총점과 무관하게 불합격
- 기본은 **50문항 정식 구성**. 시간이 부족할 때 쓰는 40문항 축약 구성도 선택 가능
- Part 2와 Part 3는 응시할 때마다 은행에서 무작위 추출. 덜 나온 문항을 먼저 뽑으므로 은행을 한 바퀴 돌기 전에는 같은 문항이 재출제되지 않음 (출제 이력은 `seen` 키에 저장)
- 평가 역량 6종: 문제정의, 프롬프트 설계, 보안 및 윤리, 결과 검증, 비즈니스 판단, 업무 통합

## 세 가지 모드

| 탭 | 용도 |
|---|---|
| 모의시험 | 실전과 같은 구성으로 140분 응시 |
| 스프린트 | 60초 / 120초 안에 객관식을 최대한 푸는 미니게임. 틀린 문항은 오답 노트로 넘어갑니다 |
| 실습 | 교재 13개 챕터의 실습 과제 47개. 직접 작성 후 예상 답안과 점검 항목으로 비교 |
| 이론 | **역량별 정리**(6대 역량 + 프롬프트 구조 7개 절)와 **용어 사전**(63개, 검색·분류·관련어 이동) 두 가지 보기 |

## 기능

- 문항별 난이도(상·중·하)와 배점을 상단에 표기
- 문항마다 `정답 확인` 버튼으로 즉시 정답 공개 — 출제 주제, 평가 역량, 해설, 보완점 표시
- OMR 답안지 형태의 진행 레일에서 응답 여부와 채점 결과를 한눈에 확인
- 채점 후 총점, 파트별 점수, 6대 역량별 점수, 취약 역량, 문항별 검토 리포트 제공
- 서술형은 모범답안과 배점이 매겨진 루브릭 체크리스트로 자가 채점
- 응시 기록 저장 — 회차별 점수와 파트별 점수가 브라우저에 남고, 2회차부터 총점 추이 그래프가 그려집니다
- 오답 모드 — 맞히지 못한 문항만 모아 다시 풀고, 정답 처리하면 오답 노트에서 자동으로 빠집니다
- 이어풀기 — 시험 도중 창을 닫아도 응답·해설 열람 상태·경과 시간까지 복원됩니다
- 스프린트 최고 기록과 연속 정답 기록 저장
- 실습 과제 답안과 점검 항목 체크 상태 저장, 챕터별 진행률 표시
- 용어 사전 63개 — 정의는 새로 작성했고, 객관식에서 갈리는 지점 24개에 시험 포인트를 덧붙임

## 저장 방식

기록은 브라우저 `localStorage`에 저장됩니다(키: `apex-mock/v1`). 서버가 없으므로 기기 간 동기화는 되지 않고, 같은 브라우저에서만 유지됩니다. 저장소를 쓸 수 없는 환경에서는 자동으로 메모리 모드로 내려가 새로고침 시 초기화됩니다. 시작 화면 하단의 `기록 전체 삭제`로 언제든 비울 수 있습니다.

## 배포

### GitHub Pages

```bash
git init
git add index.html README.md
git commit -m "APEX 모의시험 사이트"
git branch -M main
git remote add origin https://github.com/<계정>/apex-mock.git
git push -u origin main
```

푸시 후 저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 로 설정하면
`https://<계정>.github.io/apex-mock/` 에서 열립니다. 반영까지 1~2분 걸립니다.

### Cloudflare Pages / Netlify

`index.html`이 든 폴더를 대시보드에 드래그하면 끝입니다. 빌드 명령 없음, 출력 디렉터리는 루트로 둡니다.

### 로컬 확인

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 문항 수정

`index.html` 안의 `PART1`, `PART2`, `PART3` 배열을 편집하면 됩니다.

```js
{
  id:"P1-31", diff:"중", comp:"결과 검증", topic:"출제 주제명",
  q:"문항", opts:["1","2","3","4"], a:0,
  why:"해설", fix:"보완점",
  ext:true   // 50문항 모드에서만 출제
}
```

Part 2의 `type`은 `order`(순서 배열), `multi`(복수 선택), `write`(작성형)를 지원합니다.
`write`와 Part 3의 `rubric` 배점 합은 각각 20점, 80점을 맞춰야 총점이 1,000점으로 떨어집니다.
